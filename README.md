# 选课工具

现有 Python/Tkinter 版本的独立 Rust 重构。功能包括：

- Rust 原生 ddddocr 验证码识别（内嵌 ONNX 模型，不依赖 Python/OpenCV）
- 登录、普通/实验轮次选择
- 从所选轮次页面动态识别 `FAWKC` / `TJKC` / `XGKC` 等课程类型
- 分页抓取、搜索过滤、仅显示可选课程、仅显示未满课程
- 多选课程、余量监控、定时开始、重复抢课、保活、暂停与停止
- 可选的掉线自动登录，以及“确认 B 有空位后再退 A”的换课模式

## 余量监控与掉线恢复

“任意未满课程自动选（无需勾选）”开启后，点击“开始任意课程监控”即可按照官方页面的查询方式持续 `POST /xsxk/elective/clazz/list`，请求体携带 `SFYM: "0"`（查询未满课程）。该模式不要求勾选目标，会按查询结果顺序尝试未满且状态可选的课程，并在第一门选课成功后停止，避免一次选中多门。关闭该模式后，普通抢课仍要求先勾选目标课程。A→B 换课继续独立监控 B 的余量。“仅显示未满课程”只影响当前列表显示，当前已选课程仍会保留，便于设置换课。

“掉线自动登录”默认关闭。开启后，仅当接口明确返回选课系统登录页（HTTP 200 HTML）时触发，每个任务最多重新登录一次，并重新进入原课程轮次后继续。普通网络错误、未知 HTML、安全验证页和 VPN 网关错误不会触发反复登录。A→B 换课一旦开始提交退 A，任何结果不确定的状态变更都不会被自动重放，以免重复退选或误判结果。

## 构建

```powershell
cargo build --release
```

输出：`target\release\xk-rust.exe`

首次构建会下载 Rust ddddocr 依赖和 ONNX Runtime 静态库，因此耗时较长。

## 安全

偏好和课程缓存保存在 `%LOCALAPPDATA%\DNUI-XK\`，不会在可执行文件目录生成 JSON 文件。仓库不会复制 Python 版的账号、密码或课程缓存。
