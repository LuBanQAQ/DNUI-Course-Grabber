# DNUI 选课工具（Rust）

面向大连东软信息学院选课系统的 Windows 桌面工具。项目将原 Python/Tkinter 版本重写为 Rust 原生 GUI，提供课程抓取、课程筛选、重复抢课和换课辅助功能。

## 功能

- Rust 原生 ddddocr 验证码识别，内嵌 ONNX 模型，不依赖 Python 或 OpenCV。
- 登录选课系统，选择普通、实验等选课轮次。
- 自动识别轮次页面中的 FAWKC、TJKC、XGKC 等课程类型。
- 分页抓取课程，支持课程号、课程名、教师、星期、节次和地点关键词搜索。
- 仅显示可选课程，支持多选课程。
- 定时开始、重复提交、暂停、停止和请求保活。
- 支持 A→B 有位换课流程，并在不确定响应时停止后续操作。
- 通过独立 WebView2 窗口完成校园 VPN/教务系统网页登录。
- 导入“我的课表”，按大节和已有课程冲突筛选选修课。

## 基本使用

1. 启动 xk-rust.exe。
2. 输入学号和密码，点击“登录并抓取本轮课程”。
3. 选择可用的选课轮次。
4. 在课程列表中搜索、筛选并勾选目标课程。
5. 根据需要设置定时开始、点击次数、点击间隔和保活参数。
6. 点击“开始抢课”或使用换课功能。

程序不会替用户确认选课结果。提交返回 HTML、无法解析或网络中断时，结果可能不确定，程序会停止后续操作；请先登录官方系统核对实际选课状态。

## 课表筛选

### 导入课表

1. 点击“导入我的课表”。
2. 在独立窗口中完成教务系统登录。
3. 如果当前在工作台首页，点击“打开我的课表”；程序会跳转到教务系统的课表页面。
4. 等待课表完整显示后，点击页面底部的“导入当前课表”。
5. 返回主界面，先抓取课程，再点击“按课表筛选”。

课表导入窗口使用教务系统页面中的 DOM 提取课程名称、星期、周次和节次。课表只在本次运行内存中使用，程序不会读取常用浏览器 Cookie，也不会把课表写入磁盘。

### 大节映射

“大节筛选”按连续双节映射：

| 大节 | 选课系统节次 |
| --- | --- |
| 第 1 大节 | 1-2 |
| 第 2 大节 | 3-4 |
| 第 3 大节 | 5-6 |
| 第 4 大节 | 7-8 |
| 第 5 大节 | 9-10 |
| 第 6 大节 | 11-12 |
| 第 7 大节 | 13-14 |

### 冲突筛选

点击“按课表筛选”后，程序会按以下条件判断冲突：

- 星期相同；
- 节次区间重叠；
- 周次区间重叠；
- 单双周相容时视为重叠。

周次信息缺失时按可能冲突处理。已选课程不会因为课表筛选被隐藏。

界面会显示以下诊断信息：

- 导入的课表记录数；
- 成功识别课程时间的课程数；
- 总冲突课程数；
- 当前列表实际减少的课程数；
- 当前课程列表显示数和总数。

如果勾选“仅显示可选课程”，选课系统已经标记为冲突的课程可能在课表筛选前就被隐藏，因此“总冲突数”不一定等于当前列表减少数。再次点击按钮可取消课表筛选。

关键词搜索、大节筛选和课表冲突筛选可以同时使用。重新导入课表、重新抓取课程或清除课表时，旧筛选结果会自动重置。

## 校园网、aTrust 与 VPN

校内请连接校园网。校外访问请按学校要求连接 aTrust/VPN，并访问校园 VPN 门户 https://vpn.neuedu.com 完成认证。

程序提供以下入口：

- “VPN 浏览器授权”：在独立 WebView2 窗口中完成学校网页登录，并将选课站点所需的会话交给桌面 HTTP 客户端；
- “打开校园 VPN”：打开学校 VPN 门户；
- “检测校园网/VPN”：只请求真实验证码接口，检测网络访问能力，不提交账号密码或选课请求。

aTrust 客户端显示“已上线”不一定意味着桌面 HTTP 客户端已经拥有选课站点所需的 Web 会话。独立授权窗口不会复用 Chrome、Edge 或外部 aTrust 客户端的浏览器 Cookie，因此必要时需要在窗口内重新完成网页登录。

如果普通浏览器能访问、程序仍要求 VPN 验证，可能是浏览器已有认证会话，或学校使用了应用级转发策略。程序不会重放临时网关链接，也不会绕过校园访问控制；检测失败时会明确提示，不会伪装成连接成功。

## 运行环境

- Windows 10/11。
- Microsoft Edge WebView2 Runtime，用于 VPN 授权和课表导入窗口。
- 能访问学校教务系统和选课系统的校园网或 VPN/aTrust 网络环境。

WebView2 使用独立会话。运行数据目录通常位于：

    %LOCALAPPDATA%\DNUI-XK\vpn-webview\

## 构建

需要 Rust stable 工具链。Windows PowerShell：

    cargo build --release

输出文件：

    target\release\xk-rust.exe

首次构建会下载 ddddocr 和 ONNX Runtime 相关依赖，耗时可能较长。

运行测试：

    cargo test
    cargo fmt --all -- --check
    node --check src/vpn_auth.js

部分测试需要真实选课服务、账号或 WebView2，因此默认按条件忽略。

## 数据与安全

- 学号、密码和应用偏好保存在 %LOCALAPPDATA%\DNUI-XK\xk-rust-prefs.json。
- 课程抓取缓存保存在 %LOCALAPPDATA%\DNUI-XK\xk-courses.json，不会生成在可执行文件目录。
- VPN 授权会话只保存在当前进程内存中，通过匿名管道传递，不写入偏好文件、日志或命令行参数。
- 课表导入不读取外部浏览器 Cookie，课表数据不会持久化。
- 请勿在日志、截图或 issue 中公开学号、密码、Cookie、验证码链接或带认证参数的 URL。

## 已知限制

- 学校教务系统页面结构变化时，课表 DOM 解析器可能需要更新。
- WebView2 授权窗口不共享外部浏览器或 aTrust 客户端的登录状态。
- 关闭程序后需要重新导入课表和重新授权 VPN 会话。
- 选课接口返回异常或网络中断时，程序无法保证服务器端提交结果，必须以官方系统显示为准。
